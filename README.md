# Turmalina — workspace do Dev Júnior

Este repositório é o meu ambiente de trabalho na **Turmalina**, uma startup (fictícia) de EdTech/SaaS onde atuo como **desenvolvedor júnior**. É uma simulação de trabalho real: tickets, prazos, code review, reuniões, clientes e mentoria.

## Por onde começar

1. [`docs/empresa.md`](docs/empresa.md) — a empresa, o produto, a equipe, a stack e os objetivos.
2. [`docs/onboarding.md`](docs/onboarding.md) — meu cargo, fluxo de Git/PR, definição de pronto.
3. [`docs/status-do-dev.md`](docs/status-do-dev.md) — minhas tarefas, avaliações e evolução.
4. [`docs/tickets/`](docs/tickets/) — os tickets.

## Estrutura

```
apps/
  matricula-publica/   Página pública de matrícula (HTML/CSS/JS legado do MVP)
docs/
  empresa.md           Tudo sobre a Turmalina
  onboarding.md        Padrões e fluxo de trabalho
  status-do-dev.md     Quadro de tarefas e histórico de avaliações
  tickets/             Tickets (espelho do Linear)
.github/
  pull_request_template.md
```

## Comandos da simulação

| Comando | O que faz |
|---|---|
| `/startup` | Estado atual da empresa, equipe, produto e prioridades |
| `/daily` | Reunião diária: o que fiz, o que vou fazer, bloqueios |
| `/tasks` | Minhas tarefas pendentes |
| `/newtask` | Uma nova demanda realista para o meu nível |
| `/senior` | Sessão de mentoria de ~30 min com o Thiago (Dev Sênior) |
| `/review` | Code review profissional do código / PR que eu enviar |
| `/meeting` | Reunião de equipe ou planejamento |
| `/client` | Conversa com um cliente com problema ou pedido |
| `/career` | Avaliação da minha evolução e lacunas |
| `/sprint` | Organização de uma sprint |
| `/retrospective` | Retrospectiva do meu desempenho e do trabalho |
| `/help` | Lista os comandos |

> Se o app interceptar algum comando (ex.: `/help`), escreva sem a barra: `help`, `review` etc.
